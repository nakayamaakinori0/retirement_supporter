# フォント一覧タブを削除する

- Issue: #17
- Status: Approved

## 背景 / 目的

フォント一覧タブは、退職願・退職届のフォント選定を検討するための開発者向け確認画面として作られたもの。
端末で利用可能なフォント名をただ並べているだけで、エンドユーザーにとっての価値がない。
タブが3つあるうちの1つを占有しており、アプリの目的（退職日までのカウントダウンと退職届の作成）をぼかしている。

## スコープ

### やること

- タブから「フォント」の導線を削除する
- 画面ファイル `app/(tabs)/font-styles.tsx` を削除する
- 未使用になる型定義 `MainTabParamList.FontStyles` を削除する

### やらないこと

- 残る2タブのレイアウトやデザインの調整
- 退職届で使用しているフォント（`Papyrus`）の変更
- タブの並び順の変更

## 仕様

### 画面 / UI

タブが3つから2つになる。

| 変更前 | 変更後 |
| --- | --- |
| 退職願・退職届 / ホーム / フォント | 退職願・退職届 / ホーム |

`app/(tabs)/_layout.tsx` の `Tabs.Screen name="font-styles"` を削除する。
Expo Router はファイルベースルーティングなので、画面ファイルの削除によりルート `/font-styles` 自体も消える。

### 振る舞い

- タブバーに「フォント」が表示されない
- 初期表示タブは変更しない（現状の挙動を維持する）

### データ / 状態

変更なし。フォント一覧画面は state も永続化も持たない純粋な表示のみの画面。

## エッジケース

- `/font-styles` への直リンクは存在しない（アプリ内から遷移する導線は `_layout.tsx` のタブ定義のみ）
- 削除する画面を参照しているテストは存在しない

## 受け入れ条件

- [x] タブバーに「フォント」が表示されない
- [x] `app/(tabs)/font-styles.tsx` が存在しない
- [x] `FontStyles` への参照がリポジトリ内に残っていない
- [x] `npm run typecheck` / `npm run lint` / `npm test` が通る

## テスト方針

フォント一覧画面に対する既存テストはないため、テストの削除・追加は不要。
残る2タブが従来どおり描画されることは既存のテストと手動確認でカバーする。

## 影響範囲

- `app/(tabs)/font-styles.tsx`（削除）
- `app/(tabs)/_layout.tsx`（タブ定義から1件削除）
- `src/types.ts`（`MainTabParamList.FontStyles` を削除）

## 未決事項

なし。
