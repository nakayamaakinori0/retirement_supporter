# 実機確認手順（開発ビルド）

広告SDK（`react-native-google-mobile-ads`）はネイティブコードを含むため、**Expo Go では動作しません**。
実機で確認するには EAS Build で開発ビルドを作る必要があります。

所要時間の目安は、初回が 40〜60分（うち待ち時間が大半）、2回目以降は 15〜20分です。

---

## 0. 事前準備（初回のみ）

### 必要なもの

- Expo アカウント（無料。未登録なら https://expo.dev で作成）
- Apple Developer Program の有効なアカウント（年額 $99。v1 を公開しているので既にあるはず）
- iPhone 実機と USB ケーブル（初回のデバイス登録で使用）

### EAS CLI にログインする

```bash
npx eas login
```

Expo アカウントのメールアドレスとパスワードを入力します。

```bash
npx eas whoami   # ログインできているか確認
```

### プロジェクトを EAS に紐付ける

```bash
npx eas init
```

`app.json` に `extra.eas.projectId` が追記されます。**この変更はコミットしてください**（次回以降の紐付けに必要です）。

---

## 1. 実機を登録する

開発ビルドは、登録済みのデバイスにしかインストールできません。

```bash
npx eas device:create
```

対話形式で聞かれるので、以下を選びます。

| 質問 | 選ぶもの |
| --- | --- |
| How would you like to register your devices? | **Website** |

URL と QR コードが表示されます。**確認したい iPhone の Safari で** その URL を開き、
表示に従ってプロファイルをインストールします。

インストール後、iPhone 側で以下も必要です。

1. 設定 → 一般 → VPNとデバイス管理 → ダウンロード済みプロファイル → インストール
2. 設定 → 一般 → 情報 → 証明書信頼設定 → 該当プロファイルをオン

登録できたか確認します。

```bash
npx eas device:list
```

---

## 2. 開発ビルドを作る

```bash
npx eas build --profile development --platform ios
```

初回は Apple アカウントの認証を求められます。

| 質問 | 答え |
| --- | --- |
| Apple ID | Apple Developer に登録しているメールアドレス |
| Do you want to log in to your Apple account? | **Yes** |
| Generate a new Apple Distribution Certificate? | **Yes** |
| Generate a new Apple Provisioning Profile? | **Yes** |

証明書は EAS が管理してくれるので、Xcode を触る必要はありません。

ビルドはクラウドで走ります。**10〜30分ほどかかります**。
完了すると URL と QR コードが表示されるので、**iPhone のカメラで QR を読み取ってインストール**します。

### ビルドが失敗したら

```bash
npx eas build:list --platform ios --limit 1     # 直近のビルドとログURLを表示
```

ログURLをブラウザで開くと、どの段階で落ちたか確認できます。

---

## 3. 開発サーバーを起動してアプリを繋ぐ

```bash
npx expo start --dev-client
```

`--dev-client` を付けるのが重要です（付けないと Expo Go 向けの起動になります）。

iPhone にインストールした「retirementSupporter」アプリを開き、
表示された開発サーバーに接続します。PC と iPhone が**同じ Wi-Fi にいる必要があります**。

繋がらない場合はトンネル経由を試します。

```bash
npx expo start --dev-client --tunnel
```

---

## 4. 確認する項目

### 4-1. App Tracking Transparency（ATT）

**アプリを初めて起動したとき**にトラッキング許可のダイアログが出ることを確認します。

- [ ] 「"retirementSupporter"にトラッキングを許可しますか？」のダイアログが表示される
- [ ] 文言に「広告をお客様に合わせて表示するために使用します。許可しなくてもアプリのすべての機能をご利用いただけます。」が含まれる
- [ ] 「許可しない」を選んでも、アプリが正常に動く

> このダイアログは**一度しか出ません**。もう一度見たい場合は、
> 設定 → プライバシーとセキュリティ → トラッキング でアプリを一度オフにするか、
> アプリを削除して入れ直してください。

### 4-2. 広告の表示（本命）

「退職願・退職届」タブ → 必要事項を入力 → 確認画面 → **「生成」をタップ**。

- [ ] 「生成」タップ後、**全画面のテスト広告**が表示される
- [ ] 広告に「Test Ad」という表示がある（**重要**。下記の注意を参照）
- [ ] 広告を閉じると、PDFの共有シートが表示される
- [ ] 共有シートから PDF を保存・確認でき、内容が入力どおりである

> ⚠️ **必ず「Test Ad」表示があることを確認してください。**
> 開発ビルドでは `__DEV__` が true になり、Google が用意したテスト広告IDが使われます。
> もし実際の広告が表示された場合は実IDを読み込んでいるということで、
> AdMob のポリシー上「無効なトラフィック」と判定されアカウント停止のリスクがあります。
> その場合はすぐに使用を止めて報告してください。

### 4-3. 広告が出せないときのフォールバック（重要）

**広告が理由でPDF生成が止まらないこと**が、この機能の最優先の要件です。

iPhone を**機内モードにして**から「生成」をタップします。

- [ ] 広告は表示されない
- [ ] **5秒ほど待つと、広告なしでPDFの共有シートが表示される**
- [ ] エラーダイアログは表示されない

機内モードを解除して元に戻します。

### 4-4. 連打の抑止

- [ ] 「生成」を素早く3回タップしても、広告とPDF生成は1回ずつしか走らない
- [ ] 処理中はボタンがローディング表示になり、押せなくなる

### 4-5. 既存機能の回帰確認

広告の導入で壊れていないことを確認します。

- [ ] ホームタブで退職日を設定でき、残り営業日が表示される
- [ ] 「やること」タブで項目をチェックでき、**アプリを再起動しても状態が残る**
- [ ] タブが3つ（退職願・退職届 / ホーム / やること）で、フォントタブが消えている

---

## 5. 確認できたら

結果を Issue か PR にコメントで残します。問題があった場合は、以下を添えると原因を追いやすくなります。

- どの手順で何が起きたか
- 開発サーバーのターミナルに出たログ
- 可能なら画面の録画

---

## 補足：本番ビルドとストア提出

実機確認が通ったあとの流れです。**今はまだ実行しないでください。**

```bash
npx eas build --profile production --platform ios   # 本番ビルド
npx eas submit --platform ios                        # App Store Connect へ提出
```

提出前に必要なこと:

- App Store Connect でプライバシー情報を更新する（広告の導入により「使用状況データ」「識別子」の申告が必要）
- AdMob 管理画面でアプリとストアの紐付けを完了する
- `app.json` の `version`（現在 `2.0.0`）と `ios.buildNumber` を確認する

## 既知の制約

- Expo Go はこのアプリで使えなくなりました。開発は常に開発ビルド + `--dev-client` で行います
- 依存を追加・更新したときは、開発ビルドを作り直す必要があります（JSの変更だけなら不要）
- Android は AdMob のアプリ登録が未了のため未対応です
